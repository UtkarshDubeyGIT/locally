# Locally frontend mockups

Open [`mockups/phase-1/index.html`](../../mockups/phase-1/index.html) in a browser. Use the Phase 1 / Phase 2 selector in the top bar to move between the original manual-first product and the Phase 2 prototype.

## Phase 2 UI Prototype

Phase 2 demonstrates how Locally can support an agency managing 5–15 clients by automatically synchronizing data, surfacing changes, preparing review drafts, compiling weekly updates, refreshing competitor facts, and scheduling reminders.

Human approval remains mandatory for public review replies, reports, sensitive Google Business Profile changes, and high-risk issues. Exact local ranking observations remain manually entered or imported, competitor conclusions remain analyst-reviewed, and client discovery remains human-led.

This is a screenshot-ready, UI-only prototype. It uses static seeded data and small local visual state changes; there are no backend routes, OAuth flows, jobs, database changes, real publishing, model calls, or email delivery.

The represented integrations—Google Business Profile, PageSpeed Insights, Google Places, and an email provider—are mocked. Manual entry remains available in the UI when any integration is unavailable.
